# DLHI RLH ECOM LLC

Modern coastal marketplace storefront for **DLHI RLH ECOM LLC** — Delray Beach, Florida.

Tagline: *Modern Living, Beautifully Simple.*

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui + Radix UI
- Framer Motion + Embla Carousel

## Development

```bash
npm install
npm run dev
```

## Notes

- Cart, wishlist, search, filters, and product browsing are fully functional (localStorage).
- Login, registration, password recovery, checkout, and payment are demo-only.
- No company email is configured; contact surfaces intentionally omit email.
